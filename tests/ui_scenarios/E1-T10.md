# E1-T10 — WebUI 上傳與摘要頁

## 怎麼啟動

```bash
horos init ./demo_project
horos ui ./demo_project
# 瀏覽器開 http://localhost:5000
```

## 測試步驟

1. 準備一包資料集 zip：COCO（內含 `_annotations.coco.json`，flat 或 train/valid/test 子目錄皆可）或 YOLO（內含 `data.yaml`）
2. 開啟首頁，把 zip 拖進虛線框（或點擊選檔）
3. 上傳中應顯示「Uploading and parsing …」狀態文字
4. 完成後應顯示解析摘要列：`Imported N images, M annotations, K classes (COCO/YOLO)`
5. 「Dataset summary」卡片應出現：影像數、標註數、類別數、train/valid/test 計數
6. 「Instances per class」表格應列出每個類別的實例數、涵蓋影像數與相對長條圖
7. 「Validation」區塊應顯示問題清單（乾淨資料集顯示綠色 No issues found；壞資料顯示 `[kind] message`，warning 黃色、error 紅色）
8. 「Available models」表格應列出 RF-DETR Nano/Small/Medium/Large 與 OWLv2，每列尾端有綠色 Apache-2.0 授權標示（E4-S2）
9. 上傳一個非 zip 檔或格式無法辨識的 zip，狀態列應顯示紅色 `Import failed: <明確原因>`，頁面不得卡死

## 預期結果

非工程使用者上傳一包 zip 即看到完整解析摘要（幾張圖、幾個類別、每類幾個實例），錯誤情境有明確訊息（E1-S3、E1-S4）

## 已知限制

- 上傳大小上限 2 GB（更大的資料集請用 `horos import` 走檔案路徑）
- 頁面尚無標註入口與影像縮圖牆（E2 標註 UI 時加入）
- 模型表格目前只是資訊展示，選用模型的流程屬 E5 訓練 UI
