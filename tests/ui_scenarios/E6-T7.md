# E6-T7 — 上傳測試 UI（Evaluate 頁）

## 啟動

```
horos ui <project>          # 專案需至少有一個 completed 的訓練 run
瀏覽器開 http://localhost:5000/evaluate （或右上角準星 icon）
```

## 測試步驟

### A. 模型選擇

1. 「Model under test」下拉列出所有 completed 的 run（id + 模型名）；
   沒有任何 completed run 時顯示「train a model first」提示
2. 切換 run 會自動載入該 run 已保存的評估報告（若有）

### B. 單張照片測試（E6-S1, E6-S3）

3. 拖一張新照片進虛線框（或點擊選檔）：
   - 立刻顯示偵測結果疊圖：類別色框 + 類別名 + 信心度標籤
   - 狀態列顯示「N detection(s) above 0.05」
4. 拉動 Confidence 滑桿：
   - 框的顯示即時增減，**無伺服器往返**（推論以 0.05 低門檻做一次，
     滑桿在前端過濾）
   - 右側顯示「N shown at ≥ t」

### C. 保留集指標（E6-S4 的 UI 入口）

5. 選 Split（test / valid）按「Run evaluation」：
   - 進度條顯示 k/N images
   - 完成後顯示四張指標卡（mAP@[.5:.95]、mAP@50、mAP@75、mAR@100）
   - 每類表格：instances、AP@50、AP@[.5:.95]、AP bar
   - 底部顯示影像數、GT 框數、評估時間
6. 報告持久化在 runs/<id>/eval/<split>.json，重新整理頁面後選同一
   run + split 仍能看到

### D. 錯誤路徑

7. 對不存在的 split 評估：同步收到明確錯誤（不會產生 job）
8. 選擇未完成（failed/stopped/running）的 run 不會出現在下拉中

## 預期結果

上傳一張新照片幾秒內看到偵測疊圖；滑桿即時改變顯示門檻；
一鍵在保留集上取得完整 COCO 指標與每類 AP
