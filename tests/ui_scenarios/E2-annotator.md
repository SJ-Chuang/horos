# E2 — 標註介面（E2-T1 畫布、E2-T2 bbox、E2-T3 polygon、E2-T5 快捷鍵）

## 怎麼啟動

```bash
horos init ./demo_project
horos import <資料集目錄或解壓後的 zip> --project ./demo_project
horos ui --project ./demo_project
# 瀏覽器開 http://localhost:5000 → 右上「Open annotator →」，或直接開 /annotate
```

## 快捷鍵對照表（頁面內按 `?` 亦可查看）

| 鍵 | 動作 |
|---|---|
| `1`–`9` | 切換目前類別；選取中的框/多邊形則改指派類別 |
| `V` | 選取編輯模式 |
| `W` | 畫框模式（拖曳畫框） |
| `P` | 多邊形模式（逐點點擊，Enter 或點回起點閉合） |
| `Esc` | 取消繪製 / 取消選取 |
| `Backspace`（繪製多邊形中） | 刪除上一個點 |
| `Delete` / `Backspace` | 刪除選取的標註 |
| `D` / `A` | 下一張 / 上一張 |
| `Ctrl+Z` | 復原（單張影像內） |
| `Space`+拖曳 | 平移；滾輪＝以游標為中心縮放；`0`＝適配視窗 |

## 測試步驟

### A. 畫布（E2-T1）
1. 開啟 /annotate，第一張影像應自動載入並適配視窗
2. 滾輪縮放：畫面以游標位置為中心縮放，右上顯示縮放百分比
3. 按住 Space 拖曳（或中鍵/右鍵拖曳）平移；按 `0` 回到適配

### B. bbox（E2-T2）
1. 按 `W`，拖曳畫一個框：放開後框保留、以目前類別上色，右上顯示 `saved · vN`
2. 按 `V` 點選該框：出現 8 個控制點；拖曳角/邊改大小、拖曳內部移動——每次
   放開滑鼠右上版本號 +1（每動作即存）
3. 選取後按 `2`：框的顏色與標籤換成第二個類別
4. 選取後按 `Delete`：框消失；按 `Ctrl+Z`：框回來
5. 重新整理頁面：所有標註仍在（E2-S2 斷點續標）

### C. polygon（E2-T3）
1. 按 `P`，逐點點擊畫出至少三點，點回起點（或按 Enter）閉合
2. 按 `V` 選取该多邊形：頂點出現控制點，拖曳頂點改形狀、拖曳內部整體移動
3. 繪製中按 `Backspace` 可刪上一點、`Esc` 放棄

### D. 快捷鍵與佇列（E2-T5 / E2-T7）
1. 全程用鍵盤：`1` 選類別 → `W` 畫框 → `D` 下一張 → `A` 回上一張，不碰選單
2. 左側佇列切「Only unannotated」：清單只剩未標影像；標完一張後它從清單消失
3. 左側進度條隨標註即時更新

### E. 多人（E2-S6，開兩個瀏覽器視窗模擬）
1. 視窗 1 開啟某張影像後，視窗 2 的清單該張出現 🔒，開啟時頂欄顯示
   「⚠ someone else is annotating this image」
2. 兩邊同時改同一張並儲存：後儲存者看到紅色 toast「Someone else saved this
   image first. Reloaded their version」，畫面自動載入對方版本，資料不互相覆蓋

## 預期結果

標註者全程鍵盤操作完成畫框、改框、換類別、換頁；關掉瀏覽器再回來進度完整保留。

## 已知限制

- polygon 不支援插入新頂點（僅拖曳既有頂點）；無 redo（僅 undo）
- 類別刪除/改色未做進標註頁側欄（雙擊類別可改名；完整管理走 API）
- 影像清單為完整清單，數千張以上未做虛擬捲動
